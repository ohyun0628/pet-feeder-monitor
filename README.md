# Raspberry Pi 스마트 펫 사료 모니터

초음파 센서로 사료 잔량을 재고, 온습도·조도·카메라와 함께 웹 대시보드에서 급식 상태를 확인하는 IoT 프로젝트입니다.

2026학년도 모바일스마트시스템 라즈베리 프로젝트.

### 요구사항
1) 사료통 위쪽 초음파 센서로 센서~사료 표면 거리를 측정하고, 가득 참/빈 통 보정값으로 잔량(%)을 계산한다.
2) 잔량이 경고 기준(기본 20%) 이하이거나 습도가 높으면 LED가 켜지고, 웹에도 경고가 표시된다.
3) 온습도 센서(HTU21D)로 사료통 주변 온·습도를 웹에서 확인한다.
4) 조도 센서로 낮/밤을 구분한다.
5) 물리 버튼 또는 웹의 **급식 기록하기**를 누르면 USB 카메라로 사진을 찍어 시각·잔량과 함께 히스토리에 남긴다.
6) MQTT로 센서 상태를 웹에 실시간 전송하고, 웹에서 LED 제어·사료량 보정이 가능하다.
7) 잔량 변화 그래프와 급식 기록 목록을 대시보드에 보여 준다.

---

## 시스템 구조

지연을 줄이고 센서/웹을 분리하기 위해 **Publisher-Subscriber(MQTT)** 를 사용합니다.

* **Raspberry Pi (Publisher)**: `monitor.py`가 초음파·온습도·조도를 주기적으로 읽고, 급식 시 OpenCV로 사진을 저장한 뒤 MQTT로 상태를 발행합니다.
* **MQTT Broker**: Mosquitto가 센서 상태(`pet/status`), 급식 기록(`pet/feed`), LED/명령(`pet/led`, `pet/cmd`)을 중계합니다.
* **Web Client (Subscriber)**: Flask(`app.py`)가 대시보드를 띄우고, 브라우저는 웹소켓(9001)으로 브로커에 붙어 차트와 기록을 갱신합니다.

```text
[초음파/HTU21D/조도/버튼/LED/카메라]
        │
        ▼
  circuit.py  →  monitor.py  --MQTT-->  mosquitto
                                       │
                                       ├─ pet/status  (잔량, 온습도, 경고)
                                       ├─ pet/feed    (급식 기록 + 사진 경로)
                                       └─ pet/led, pet/cmd  (웹 → 파이)
                                              │
                                              ▼
                                         브라우저 대시보드
                                         (Flask :8080)
```

## 하드웨어 구성

제어보드(Raspberry Pi), LED 1개, 푸시 버튼 1개, 초음파 센서 1개, 온습도 센서 1개, 조도 센서 1개, USB 카메라 1대.

| 부품 | 핀 (BCM) |
|---|---|
| LED (+220Ω) | GPIO6 |
| 버튼 | GPIO21 |
| 초음파 Trig / Echo | GPIO20 / GPIO16 (Echo는 교재 8.4 분압 회로) |
| HTU21D | GPIO2(SDA) / GPIO3(SCL) |
| MCP3202 + 조도 | MOSI 10, MISO 9, SCLK 11, CS 12 |
| USB 카메라 | USB 포트 |

초음파는 **사료통 위쪽에 달고 바닥(사료 표면)을 내려다보게** 설치합니다. 가득 차면 거리가 짧고, 비면 거리가 깁니다.

## 디렉토리 구조

```text
pet-feeder-monitor/
├── app.py                 # Flask 웹 서버 (대시보드 + 급식 기록 API)
├── circuit.py             # 센서 / LED / 버튼 / 카메라
├── monitor.py             # 측정, 경고, MQTT 발행, 급식 기록
├── mos.conf               # Mosquitto (1883 + 웹소켓 9001)
├── requirements.txt
├── static/
│   └── mqttio.js          # 브라우저 MQTT 접속
└── templates/
    └── index.html         # 대시보드
```

보정값(`calib.json`), 급식 기록(`feed_log.json`), 촬영 사진은 저장소에 올리지 않습니다.

## 실행 방법

`sudo raspi-config`에서 I2C, SPI를 켠 뒤, 가상환경에서 한 번만 설치합니다.

```bash
source ~/myenv/bin/activate
pip install -r requirements.txt
```

터미널 3개 (모두 `source ~/myenv/bin/activate` 후 `cd ~/petfeeder`):

```bash
# 터미널 1
mosquitto -v -c mos.conf

# 터미널 2
python3 monitor.py

# 터미널 3
python3 app.py
```

같은 네트워크의 PC/스마트폰에서 `http://라즈베리파이IP:8080` 접속. USB로 PC에 붙인 경우 예: `http://192.168.137.105:8080`

### 사료량 보정 (처음 한 번)
1. 통을 가득 채우고 대시보드 > 사료량 보정 > **가득 참(100%)으로**
2. 통을 비우고 **빈 통(0%)으로**

기본값: 가득 5cm, 빈 통 20cm. 센서와 사료 사이는 최소 2cm.

### 조절값 (`monitor.py` 위쪽)
- `LOW_LEVEL` 20: 잔량 경고(%)
- `HUMID_LIMIT` 70: 습도 경고(%)
- `NIGHT_LIGHT` 800: 낮/밤 기준

## 실행 결과 (시연 시나리오)

1. Mosquitto → `monitor.py` → `app.py` 순으로 실행한다.
2. 브라우저에서 대시보드를 열고 상단이 **연결됨**인지 확인한다.
3. 초음파 앞에 손/사료를 가까이 대면 잔량(%)이 올라가고, 멀리 하면 내려간다.
4. 잔량이 20% 이하이거나 습도가 높으면 LED와 경고 배너가 켜진다.
5. **급식 기록하기** 또는 GPIO21 버튼을 누르면 사진을 찍고, 오른쪽 급식 히스토리에 시각·잔량·썸네일이 추가된다. (자동 촬영 아님)
6. LED 켜기/끄기 버튼으로 경고등 수동 제어가 된다.
7. 잔량 그래프에 최근 측정값이 이어진다.

## 주요 해결 과제

* **초음파 노이즈**: 한 번만 재면 값이 튀어서, 5회 측정 후 중앙값을 쓰고 Echo 대기에는 타임아웃을 넣었다.
* **통 크기 차이**: 거리(cm)를 그대로 %로 쓰지 않고, 가득/빔 두 점을 보정해서 잔량을 계산한다.
* **소진 시각 추정**: 최근 잔량 기울기(최소제곱)로 남은 시간을 가늠하되, 거의 안 줄면 추정하지 않는다.
* **카메라 타이밍**: 실시간 스트리밍 대신 급식 기록 순간에만 한 장을 찍어, 파이 부하와 저장 용량을 줄였다.

## 문제 해결
- 거리가 계속 없음: Trig/Echo 배선·분압, 센서~사료 최소 2cm
- 온습도 오류: `i2cdetect -y 1` 에서 `0x40`
- 사진이 안 찍힘: 카메라를 **파이 USB**에 연결, `ls /dev/video*`
- 웹은 뜨는데 값이 안 옴: `mosquitto`와 9001 포트(`mos.conf`)
